## Introduction
This repository contains my solutions to various LeetCode problems. The solutions are implemented in different programming languages including Python, Java, JavaScript, and SQL. Each solution includes the problem-solving approach and is thoroughly tested.

## Repository Structure
```
leetcode/
├── python/     # Python solutions
├── java/       # Java solutions
├── javascript/ # JavaScript solutions
├── sql/        # SQL solutions
```
